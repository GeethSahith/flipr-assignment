# Flipr Placement Drive Assignment

A clean, responsive landing page built with **React (Vite)** and **plain CSS**. The UI is created from provided design assets (icons, shapes, images) and organized into small, reusable components.

## Features
- Component based layout (Header, Hero, Stats, Opportunities, Features, Footer)
- Responsive grid sections
- SVG asset usage (icons, images, shapes)
- Smooth scrolling navigation

## Project Structure
```
src/
├── assets/ (icons, images, shapes)
├── components/
├── pages/
├── styles/
├── App.jsx
├── main.jsx
└── index.css
```

## Run Locally
```bash
npm install
npm run dev
```
